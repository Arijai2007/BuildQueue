Why a job can wait with free memory

A job needs one contiguous free block. Several small holes may add up to enough memory while none is large enough.

100 × (1 − largest hole / free memory)

This external fragmentation indicator is zero when all free memory is contiguous. Internal fragmentation is zero because every reservation matches the requested size.

Reservations model memory allocation; they do not control Linux physical RAM.
